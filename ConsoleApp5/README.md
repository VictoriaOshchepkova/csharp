# Лабораторная работа №5

## Структура
Программа состоит из 3 файлов:
1. `Program.cs` - содержит главный метод Main, где организован вызов всех методов с дружественным интерфейсом
2. `PizzaRepository.cs` - содержит класс с методами для работы с базой данных
3. `Client.cs`, `Order.cs`, `OrderItem.cs`, `Menu.cs` - содержит классы, описывающие объекты в базе данных

# Алгоритм работы

## Задание №8
### Описание:
В файле LR5-var8.xls приведён фрагмент базы данных «Пиццерия». База данных состоит из четырёх таблиц. Таблица «Клиенты» содержит данные о клиентах: фамилия, имя, отчество и место жительства. Таблица «Заказы» содержит записи о совершённых заказах. Поле Статус доставки содержит информацию о том был доставлен заказ или нет, если заказ был доставлен, то к цене заказанных блюд добавляется стоимость доставки. Таблица «Состав заказов» содержит подробную информацию о заказе, какое блюдо и в каком количестве было заказано. Таблица «Меню» содержит информацию о блюдах, имеющихся в пиццерии.

### Алгоритм:
Файл `Client.cs`, `Order.cs`, `OrderItem.cs`, `Menu.cs`:
- класс Client
  - содержит поля с информацией о коде клиента, его фамилии, имени, отчества и места жительства и соответствующие свойства
  - содержит конструктор с параметрами для инициализации полей
  - переопределен метод ToString(), который выводит всю информацию о клиенте
- класс Order:
  - содержит поля с информацией о коде заказа, времени заказа, коде заказавшег, о клиента, цене доставки и статусе доставки и соответствующие свойства
  - содержит конструктор с параметрами для инициализации полей
  - переопределен метод ToString(), который выводит всю информацию о заказе
- класс OrderItem:
  - содержит поля с информацией о коде позиции заказа, коде заказа, коде блюда и количестве блюд и соответствующие свойства
  - содержит конструктор с параметрами для инициализации полей
  - переопределен метод ToString(), который выводит всю информацию о позиции в заказе
- класс Menu:
  - содержит поля с информацией о коде блюда, его названии и цене и соответствующие свойства
  - содержит конструктор с параметрами для инициализации полей
  - переопределен метод ToString(), который выводит всю информацию о блюде в меню
---
Файл `PizzaRepository.cs`:
- содержит поля для хранения записей таблиц из базы данных в виде списков и конструктор для их инициализации
- метод LoadData()
  - загружает данные из каждой таблицы в базе данных,  парсит и добавляет их в соответствующие списки
  - в случае отсутствия кода запись пропускается, в случае отсутствия значения или некорректного значения в иных ячейках - заполняет пустой строкой или 0
- метод CreateTestDB()
  - заполняет списки тестовыми данными
- метод GetClientsFromPerm()
  - возвращает списком все объекты в таблице клиентов, где в поле с местом жительства указано 'г. Пермь'
- метод GetOrdersWithClientInfo()
  - возвращает списком строки с информацией о заказе и клиенте из соединенной таблицы заказов с таблицей клиентов, где в поле со статусом заказа указано "Не выполнено"
- метод GetTotalDeliveredOrdersIncome()
  - возвращает общий доход от выполненных заказов, вычисленный из соединенной таблицы заказов с таблицей позиций заказов и таблицей меню, где для каждой позиции выполненных заказов рассчитывается стоимость как произведение количества блюд на их цену плюс стоимость доставки заказа, а затем суммируются все полученные значения.
- метод GetAverageItemsPerOrder()
  - возвращает среднее количество позиций на один заказ, вычисленное из соединенной таблицы заказов с таблицей позиций заказов и таблицей меню, сгруппированной по кодам заказов, где для каждой группы вычисляется количество блюд
- метод RemoveClient()
  - ищет клиента по коду в списке Clients
  - если не найден - возвращает false
  - иначе находит все заказы клиента, для каждого заказа удаляет связанные позиции в заказе, затем удаляет сами заказы
  - удаляет клиента и возвращает true
- метод AddClient(Client client)
  - проверяет есть ли клиенты в списке Clients
  - если есть - устанавливает код клиента как максимальный код + 1
  - иначе устанавливает как 1
  - добавляет объект в список Clients
- метод RemoveOrder(int orderId)
  - ищет заказ по коду в списке Orders
  - если не найден - возвращает false
  - иначе находит все связанные позиции заказа и удаляет их, затем удаляет сам заказ и возвращает true
- метод AddOrder(Order order)
  - проверяет есть ли заказавший клиент в списке Clients (при отсутствии генерирует исключение)
  - проверяет есть ли заказы в списке Orders
  - если есть - устанавливает код заказа как максимальный код + 1
  - иначе устанавливает как 1
  - добавляет объект в список Orders
- метод RemoveMenuItem(int dishId)
  - ищет блюдо по коду в списке Menu
  - если не найдено - возвращает false
  - иначе находит все связанные позиции заказа и удаляет их, затем удаляет само блюдо и возвращает true
- метод AddMenuItem(Menu menuItem)
  - проверяет есть ли блюда в списке Menu
  - если есть - устанавливает код блюда как максимальный код + 1
  - иначе устанавливает как 1
  - добавляет объект в список Menu
- метод RemoveOrderItem(int orderItemId)
  - ищет позицию заказа по коду в списке OrderItems
  - если не найдено - возвращает false
  - иначе удаляет позицию и возвращает true
- метод AddOrderItem(OrderItem orderItem)
  - проверяет есть ли заказ в списке Orders (при отсутствии генерирует исключение)
  - проверяет есть ли блюдо в списке Menu (при отсутствии генерирует исключение)
  - проверяет есть ли позиции заказов в списке OrdersItems
  - если есть - устанавливает код позиции заказа как максимальный код + 1
  - иначе устанавливает как 1
  - добавляет объект в список OrdersItems
- метод SaveToExcel()
  - создает новый объект Workbook, в каждой таблице в первой строке записывает соответсвующие заголовки, а затем в цикле проходится по остальным ячейкам и заполняет их данными
  - сохраняет в файл "LR5-var8_updated.xls"
  - выводит сообщение об успешном сохранении или ошибке
---
Файл `Program.cs`:
- реализован дружественный интерфейс
- вывод записей из базы данных реализован с помощью цикла вывода объектов списка в соответствующем поле из PizzaRepository.cs

# Лабораторная работа №6

## Структура
Программа состоит из 7 файлов:
1. `Program.cs` - содержит главный метод Main, где организован вызов всех методов с дружественным интерфейсом
2. `Cat.cs`, `Parrot.cs`, `IMeowable.cs`, `MeowCounter.cs`, `Funs.cs` - содержат классы и интерфейс, решающие задание №1
3. `Fraction.cs`, `IFraction.cs` - содержат классы и интерфейс, решающие задание №2
# Алгоритм работы

## Задание №1
### Описание:
№1 Кот мяукает.\
Создайте сущность Кот, которая описывается следующим образом: 
- Имеет Имя (строка)
- Для создания необходимо указать имя кота.
- Может быть приведен к текстовой форме вида: “кот: Имя”
- Может помяукать, что приводит к выводу на экран следующего текста: “Имя: мяу!”, вызвать мяуканье можно без параметров.
- Может помяукать N раз, что приводит к выводу на экран следующего текста: “Имя: мяумяу-…-мяу!”, где количество “мяу” равно N.

Создайте кота по имени “Барсик”, и затем пусть он помяукает сначала один раз, а затем три раза.

№2 Интерфейс Мяуканье.\
Разработайте метод, который принимает набор объектов способных мяукать и 
вызывает мяуканье у каждого объекта. Мяукающие объекты должны иметь метод со следующей сигнатурой: 
public void meow(); 
Дополните решение предыдущей задачи так, чтобы иметь возможность передать Кота в написанный 
вами метод и протестируйте работоспособность решения передав в него нескольких котов, а также 
создайте любой другой произвольный класс и передайте в написанный метод его объекты. 

№3 Количество мяуканий.\
Необходимо воспользоваться классом Кот и методом принимающим всех мяукающих из предыдущего 
задания. Необходимо таким образом передать кота в указанный метод, что бы после окончания его 
работы узнать сколько раз мяукал кот за время его работы. На рисунке показан пример работы. Перед 
вызовом метода создаем кота, отправляем ссылку на кота в метод, после окончания его работы 
выводим количество мяуканий на экран. Кота изменять нельзя.\

### Алгоритм:
№1 \
Класс Cat в файле `Cat.cs`:
- содержит поле с информацией о имени кота и соответствующее свойство
- содержит конструктор с параметром для инициализации поля
- переопределен метод ToString(), который выводит строковое представление кота в формате "Кот: {Имя}"
- содержит метод Meow(), который выводит в консоль одиночное мяуканье в формате "{Имя}: мяу!"
- содержит метод Meow(int count), который выводит в консоль мяуканье в формате "{Имя}: мяу-мяу-...-мяу!" (количество "мяу" равно count) с помощью цикла\  

В `Program.cs` создается объект Cat с именем "Барсик", для него вызываются методы Meow() и Meow(3).

---
№2-3\
Файл `IMeowable.cs`: содержит интерфейс IMeowable, который определяет метод Meow(), обязательный для реализации всеми "мяукающими" классами.\
Файл `Parrot.cs`: содержит класс Parrot, идентичный классу Cat, за исключением метода Meow(), который здесь выводит "{Имя}: чирик-мяу!", а метод Meow(int count) отсутствует.\
Класс-декоратор MeowCounter в файле `MeowCounter.cs`:
- содержит поля с объектом, способным мяукать, и со счетчиком мяуканий объекта и соответсвующие свойства
- содержит конструктор с параметром для инициализации полей
- содержит метод Meow(), который вызывает метод Meow() у самого мяукающего объекта и увеличивает счетчик мяуканий на 1

метод MeowsCare() класса Funs в файле `Funs.cs`:
- принимает массив объектов IMeowable
- создает словарь вида "объект - декоратор (счетчик мяуканий)"
- в цикле для каждого уникального объекта создает декоратор со счетчиком и вызывает метод Meow() через декоратор
- возвращает словарь с объектами и их счетчиками

В `Program.cs` создаются несколько объектов Cat и объектов Parrot, они в качестве параметров передаются в Funs.MeowsCare(...). Результат выводится пользователю.

## Задание №2
### Описание:
№1 Дроби.\
Создайте сущность Дробь со следующими особенностями: 
- Имеет числитель: целое число
- Имеет знаменатель: целое число
- Дробь может быть создана с указанием числителя и знаменателя
- Может вернуть строковое представление вида “числитель/знаменатель”
- Может выполнять операции сложения, вычитания, умножения и деления с другой 
Дробью или целым числом. Результатом операции должна быть новая Дробь (таким 
образом, обе исходные дроби не изменяются) (Обязательно использовать перегрузки!)
Необходимо корректно обрабатывать отрицательные значения. Учтите, что знаменатель не 
может быть отрицательным.

Затем необходимо выполнить следующие задачи: 
1. Создать несколько экземпляров дробей. 
2. Написать по одному примеру использования каждого метода. 
3. Вывести на экран примеры и результаты их выполнения в формате «1/3 * 2/3 = 2/9» 
4. Посчитать f1.sum(f2).div(f3).minus(5) 

№2 Сравнение дробей.\
Переопределите метод сравнения объектов по состоянию таким образом, чтобы две дроби 
считались одинаковыми тогда, когда у них одинаковые значения числителя и знаменателя.

№3 Клонирование дроби. Интерфейс ICloneable.\
Переопределите метод клонирования, таким образом, чтобы при его вызове возвращался новый 
объект Дроби, значения полей которого будут копиями оригинальной Дроби.

№4\
В класс Дробь, добавить интерфейс на два метода: получение вещественного значения, установка 
числителя и установка знаменателя. 
Сгенерировать такую версию дроби, которая будет кэшировать вычисление вещественного 
значения. 

### Алгоритм:
№1\
Класс Fraction в файле `Fraction.cs`:
- содержит поля для хранения числителя, знаменателя и вещественного значения дроби,а также соответсвующие свойства
- содержит конструктор с параметром для инициализации полей; дробь нормализуется с помощью метода, описанного ниже
- содержит метод Normalize(), который убирает минус перед знаменателем, а также сокращает дробь с помощью метода, описанного ниже
- содержит метод GCD(int a, int b), который вычисляет НОД двух целых чисел с помощью алгоритма Евклида
- переопределен метод ToString(), который выводит строковое представление дроби в формате "числитель/знаменатель"
- реализованы парные методы для сложения, вычитания, умножения и деления дроби с другой дробью или целым числом, которые возвращают новую дробь, а также соответствующие перегрузки операторов
   - сложение по правилу a/b + c/d = (ad + bc)/bd
   - вычитание по правилу a/b - c/d = (ad - bc)/bd
   - умножение по правилу (a/b) * (c/d) = ac/bd
   - деление по правилу (a/b) / (c/d) = ad/bc

В `Program.cs` создаются несколько объектов Fraction, выводятся примеры операций с этими дробями, а также результат f1.Sum(f2).Div(f3).Minus(5)

---
№2\
В классе Fraction переопределен метод Equals() для сравнения дробей по состоянию (сравниваются значения числителя и знаменателя).
Также переопределен сопутствующий метод GetHashCode() для генерации хэш-кода на основе значений числителя и знаменателя, обеспечивая корректную работу с коллекциями.

---
№3\
Класс Fraction реализует интерфейс ICloneable, переопределяя метод Clone() для создания нового объекта Fraction с теми же значениями
числителя и знаменателя, что и у исходной дроби.

---
№4\
Файл `IFraction.cs`: содержит интерфейс IFraction, который определяет методы
- GetRealValue() - получение вещственного значения дроби
- SetValues(int numerator, int denominator) - установка числителя и знаменателя

Класс Fraction реализует методы интерфейса IFraction
- GetRealValue() - вычисляет вещественное значение дроби, деля числитель на знаменатель, если соответсвующее поле равно null, записывает в поле (кэширует) и возвращает значение
- SetValues(int numerator, int denominator) - устанавливает значение числителя и знаменателя через свойства и нормализирует дробь.
